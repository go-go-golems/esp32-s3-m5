<article><H2 dir="auto">PicoCalc</H2> <p dir="auto">Some notes on and programs for the PicoCalc.</p> <H2 dir="auto">Hardware</H2> <ul dir="auto"> <li>comes with a <a href="https://www.raspberrypi.com/documentation/microcontrollers/pico-series.html#pico-1-family">Raspberry Pi Pico</a></li> <li>Pin-compatible devices can also be used, but need a new firmware, e.g. <ul dir="auto"> <li>Pico 2W</li> <li><a href="https://wiki.luckfox.com/Luckfox-Lyra/Introduction/">Luckfox Lyra</a></li> </ul> </li> </ul> <H3 dir="auto">Pico Pinout</H3> <ul dir="auto"> <li>for the Pico pinout see <a href="https://pico.pinout.xyz/">pico.pinout.xyz</a></li> <li>used pins <ul dir="auto"> <li><strong>IC2</strong>: GP6, GP7 (hardwired to built-in keyboard)</li> <li><strong>SPI</strong> (for the LCD): GP10, GP11, GP12</li> <li><strong>SD Card</strong>: GP17, GP18, GP19, GP16</li> <li><strong>Audio</strong> (PWM): GP26, GP27</li> </ul> </li> <li>available via pin headers <ul dir="auto"> <li>GP2, GP3, GP4, GP5, GP21, GP28</li> </ul> </li> </ul> <H3 dir="auto">LCD</H3> <ul dir="auto"> <li>ILI9488P, controlled via SPI</li> <li>Screen Resolution: 320x320px</li> </ul> <H3 dir="auto">Hardware Hacks</H3> <ul dir="auto"> <li><a href="https://steinlaus.de/rgb-led-stick-fuer-den-picocalc/">RGB LED Stick</a></li> <li><a href="https://forum.clockworkpi.com/t/rtc-inside-the-case/16484">RTC</a> (Real-time Clock)</li> <li><a href="https://forum.clockworkpi.com/t/picocalc-with-lora/16773">LoRa</a> via a ESP32 LoRa board</li> <li><a href="https://forum.clockworkpi.com/t/raspberry-pi-zero-2-on-picocalc/17946">Pi Zero2</a> replacement</li> </ul> <H2 dir="auto">Firmware</H2> <ul dir="auto"> <li><a href="https://forum.clockworkpi.com/t/luckfox-lyra-on-picocalc/16280">Luckfox Lyra Linux</a></li> </ul> <H3 dir="auto">MMBasic</H3> <ul dir="auto"> <li><a href="https://github.com/madcock/PicoMiteAllVersions">MMBasic</a> branch for PicoCalc</li> <li><a href="https://geoffg.net/Downloads/picomite/PicoMite_User_Manual.pdf">MMBasic Manual</a> (current version)</li> </ul> <H4 dir="auto">Updating the Firmware</H4> <ul dir="auto"> <li>Press Bootsel on Pi Pico</li> <li>Plug in the Device using the <strong>Mini USB</strong> connector</li> <li>You will now see the PicoCalc as a drive</li> <li>Copy the.u2f file</li> <li>Eject the drive</li> <li>Unplug the PicoCalc</li> <li>Reboot</li> </ul> <H2 dir="auto">Connecting via Serial</H2> <ul dir="auto"> <li>Use the <strong>USB C</strong> connector</li> <li>Use a terminal program (e.g., <a href="https://github.com/tio/tio">tio</a> or <a href="https://formulae.brew.sh/formula/minicom">minicom</a> on a Mac) to connect to device <ul dir="auto"> <li><code>tio /dev/tty.usberial-110</code></li> <li><code>minicom -D /dev/tty.usberial-110 -b 115200 -c</code></li> </ul> </li> <li>Settings: <ul dir="auto"> <li>115200 baud</li> <li>8N1</li> <li>Emulation VT102</li> <li>Backspace key: BS</li> <li>Enable VT102 color mode</li> </ul> </li> </ul> <H3 dir="auto">File Transfer via Serial</H3> <ul dir="auto"> <li>Enter <code>XMODEM RECEIVE</code> via console on the PicoCalc</li> <li>In Terminal Program use: XModem Send</li> </ul> <H2 dir="auto">MMBasic Tips</H2> <H3 dir="auto">Pre-defined Shortcuts</H3>
