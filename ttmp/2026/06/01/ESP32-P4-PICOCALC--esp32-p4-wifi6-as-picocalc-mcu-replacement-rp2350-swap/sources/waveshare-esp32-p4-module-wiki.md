<div role="main">          <div>  <b>ESP32-P4-Module</b> <a href="https://www.waveshare.com/esp32-p4-module.htm" title="ESP32-P4-Module"><img alt="ESP32-P4-Module" src="https://www.waveshare.com/w/upload/thumb/0/06/540px-ESP32-P4-Module.jpg/360px-540px-ESP32-P4-Module.jpg" width="360" height="270" srcset="https://www.waveshare.com/w/upload/0/06/540px-ESP32-P4-Module.jpg 1.5x"></a> <br> <br> <small>ESP32-P4NRW32, ETH/MIPI CSI/MIPI DSI</small>         <div title="Overview">  <H2>Overview</H2> <H2>Introduction</H2> <p><b>ESP32-P4-Module</b> is a dual-core RISC-V high-performance module based on ESP32-P4 chip designed by Waveshare, using ESP32-C6H8 to expand WIFI6 functionality. It supports a wide range of human-computer interfaces, including MIPI-CSI (Integrated Image Signal Processor, ISP) and MIPI-DSI interfaces, as well as common peripherals such as SPI, I2S, I2C, LED PWM, MCPWM, RMT, ADC, UART, and TWAI™. It also supports USB OTG 2.0 HS, Ethernet, and SDIO Host 3.0 for high-speed connectivity. The chip integrates a digital signature peripheral and a dedicated key management unit to ensure its security. ESP32-P4-Module is specifically designed for high-performance and high-security applications, fully meeting the higher demands of embedded applications for human-machine interface support, edge computing capabilities, and IO connectivity features. </p> <H2>Features</H2> <ul><li>Processor <ul><li>Equipped with RISC-V 32-bit dual-core processor (HP system), it features DSP and instruction set expansion, along with floating point unit (FPU), and the main frequency is up to 360MHz</li> <li>Equipped with a RISC-V 32-bit single-core processor (LP system), the main frequency is up to 40MHz</li> <li>Equipped with ESP32-C6 WIFI/BT co-processor, expand WIFI 6/Bluetooth 5 and other functions through SDIO</li></ul></li> <li>Memory <ul><li>128 KB of high-performance (HP) system read-only memory (ROM)</li> <li>16 KB of low-power (LP) system read-only memory (ROM)</li> <li>768 KB of high-performance (HP) L2 memory (L2MEM)</li> <li>32 KB of low-power (LP) SRAM</li> <li>8 KB of system tightly coupled memory (TCM)</li> <li>32 MB PSRAM is stacked in the package, and the QSPI port is connected to 16MB/32MB Nor Flash</li></ul></li></ul> <H2>Pinout Definition</H2> <p><a
