# Font Rendering Decision — stb_truetype with PT Serif

## Decision

The reader's typography stack moves from vendored Adafruit-GFX bitmap fonts
(FreeSerif 7-bit, no AA, no kerning) to **runtime TTF rasterization with a
vendored `stb_truetype.h`**, using a **PT Serif subset (Latin + Ukrainian
Cyrillic + punctuation)** embedded in firmware.

Requirements driving it: high-quality body typography, full Ukrainian
support (Ґґ Єє Іі Її, U+2019 apostrophe), kerning, and anti-aliasing on the
16-gray EPD — while preserving the architecture's hard rule that host-side
pagination and device-side rendering share exactly one metrics source.

## Alternatives considered

| Option | Verdict |
| --- | --- |
| FreeType (`espressif/freetype` managed component) | Highest quality/robustness; ~300 KB flash + ~100 KB heap + double build surface. Overkill for Latin+Ukrainian; documented escalation path if user-supplied fonts or CJK ever arrive. |
| libschrift | Smaller and defensively coded, but TrueType-only, `kern`-table-only (no GPOS pairs), less battle-tested. Preferred only if untrusted font files must be parsed. |
| Pre-rasterized AA bitmaps (extend current pattern) | Most deterministic, but fixed sizes, a new offline toolchain, no kerning without custom tooling. |
| **stb_truetype (chosen)** | ~40 KB flash, ~KBs transient RAM, single vendored header compiled identically host+device, reads `kern` **and** GPOS pair kerning, CFF support keeps font options open. |

## Constraints the implementation must honor

1. **One metrics source:** the same vendored `stb_truetype.h` and the same
   embedded font bytes produce advances/kerning on host (pagination tests)
   and device (blitting). Integer-rounded advances; no subpixel pen.
2. **Trusted fonts only:** stb_truetype is not hardened against hostile
   font files. Policy: fonts are firmware-embedded assets only. Loading
   user fonts from SD requires migrating to libschrift or FreeType first.
3. **Waveform-aware AA:** 8-bit coverage quantized to panel grays for
   Text/Quality waveform presents; thresholded to 1-bit for
   Fastest/Fast interactive presents (AA fringes threshold unpredictably
   in 1-bit modes).
4. **Reproducible asset pipeline:** the PT Serif subset is generated by a
   checked-in script (`scripts/53-subset-pt-serif.sh`) with pinned unicode
   ranges; the OFL license text is preserved alongside the font.
5. **Glyph cache in PSRAM**, explicit capacity, explicit reset-on-full
   accounting (no silent eviction surprises).

## Font choice

**PT Serif Regular/Bold** (ParaType, SIL OFL): Cyrillic-first foundry,
native Ukrainian glyph set, sturdy strokes suited to e-ink. Runner-up:
Literata (e-reader-tuned, variable). Acceptance fixture: the Ukrainian
pangram "Чуєш їх, доцю, га? Кумедна ж ти, прощайся без ґольфів!" plus
apostrophe cases ("п'ять, м'яч") rendered on the panel.

## Rollback

The GFX bitmap path remains in the code as the diagnostic fallback; if the
TTF stack misbehaves, font ids can be re-pointed at the vendored FreeSerif
data without touching pagination contracts.
