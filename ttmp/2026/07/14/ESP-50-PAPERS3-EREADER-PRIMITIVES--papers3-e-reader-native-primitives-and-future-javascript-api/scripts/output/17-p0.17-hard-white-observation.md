## Electrical aggressiveness of this operation

No rail setpoint, VCOM resistor, waveform table, scan timing, or pulse count was modified locally. PaperS3's fixed board power path was enabled only for the bounded operation and was reported idle afterward.

The operation was nevertheless a high-activity full-panel sequence: HARD clear uses four alternating full-screen phases with pass counts `6/2/4/8`, i.e. 20 scans. Codes `0x55` and `0xAA` each receive ten scans overall, with a 5 ms inter-pass delay, followed by a neutral scan. The library's clear path first requests a white target through its normal state machinery; the configured quality is HIGH. This is aggressive in scan/pulse activity but not in rail amplitude. Actual VPOS/VNEG/VGH/VGL/VCOM and current were not instrumented, so software completion cannot establish their physical values.
