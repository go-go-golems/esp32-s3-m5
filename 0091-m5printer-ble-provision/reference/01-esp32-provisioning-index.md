## Provisioning API

[\[中文\]](https://docs.espressif.com/projects/esp-idf/zh_CN/latest/esp32/api-reference/provisioning/index.html)

This document describes methods to connect a device to [Wi-Fi](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/network/esp_wifi.rst) or [Thread](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/network/esp_openthread.rst) network.

Code examples for above API are provided in the [network\_provisioning](https://github.com/espressif/idf-extra-components/tree/master/network_provisioning/examples) component.

- [SmartConfig](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/network/esp_smartconfig.html)

Code example for above API is provided in [wifi/smart\_config](https://github.com/espressif/esp-idf/tree/47faecc3/examples/wifi/smart_config).

- [Wi-Fi Easy Connect <sup>TM</sup> (DPP)](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/network/esp_dpp.html)

Code example for above API is provided in [wifi/wifi\_easy\_connect/dpp-enrollee](https://github.com/espressif/esp-idf/tree/47faecc3/examples/wifi/wifi_easy_connect/dpp-enrollee).
